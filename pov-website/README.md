# Don't put AI at the centre. Put people there.

A practitioner's point of view on AI transformation, by Shreye K. Dhaon — MBA · PMP · CSM.

## Deploy on Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com](https://vercel.com) → **Add New Project** → import this repo.
3. No build settings needed — Vercel will detect it as a static site and serve `index.html` automatically.
4. Click **Deploy**.

## Local preview

Just open `index.html` directly in any browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
